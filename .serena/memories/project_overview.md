# Project Overview: Information Design Learning App

## Project Purpose
This is a Streamlit-based web application project for creating an interactive learning experience about information design concepts. The app is intended to teach users about fundamental information design principles like abstraction, visualization, and structuring through hands-on exercises.

## Tech Stack
- **Framework**: Streamlit (Python web framework for data apps)
- **Language**: Python 3.11
- **Dependencies**: 
  - streamlit
  - pandas
- **Environment**: Docker-based dev container with Python 3.11

## Project Structure
- `streamlit_app.py`: Main application file (currently minimal)
- `requirements.txt`: Python dependencies
- `README.md`: Basic project description
- `.devcontainer/`: Development container configuration
- `.serena/`: Serena tool configuration
- `.claude/`: Claude Code configuration

## Development Environment
- Uses VS Code dev container with Python 3.11
- Automatic Streamlit server startup on port 8501
- Extensions: ms-python.python, ms-python.vscode-pylance
