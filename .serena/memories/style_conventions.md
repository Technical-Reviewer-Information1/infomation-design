# Style and Conventions

## Code Style
- Python 3.11 syntax and features
- Streamlit framework conventions
- Clean, readable code structure

## Project Conventions
- Main application entry point: `streamlit_app.py`
- Dependencies managed through `requirements.txt`
- Dev container setup for consistent environment

## Naming Conventions
- Snake_case for Python files and variables
- Clear, descriptive function and variable names
- Streamlit component naming following framework conventions

## File Organization
- Single main application file for simplicity
- Requirements clearly specified in requirements.txt
- Container configuration in .devcontainer/
