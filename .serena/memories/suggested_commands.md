# Suggested Commands

## Running the Application
- `streamlit run streamlit_app.py`: Start the Streamlit application
- `streamlit run streamlit_app.py --server.enableCORS false --server.enableXsrfProtection false`: Start with dev container settings

## Development Commands
- `pip install -r requirements.txt`: Install dependencies
- `pip install streamlit`: Install Streamlit specifically

## System Commands (Linux)
- `ls`: List directory contents
- `cd <directory>`: Change directory
- `grep <pattern> <files>`: Search for patterns in files
- `find <path> -name <pattern>`: Find files by name
- `cat <file>`: Display file contents
- `python <script>`: Run Python scripts

## Git Commands
- `git status`: Check repository status
- `git add <files>`: Stage files for commit
- `git commit -m "<message>"`: Commit changes
- `git push`: Push changes to remote repository
